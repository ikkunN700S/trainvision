# Train Vision Simulator
2026年09月04日更新（v1.0.2準拠）

## はじめに
本Webサイトはトレインビジョン®と呼ばれる近年列車内に搭載されることが増えてきた、LCD式旅客案内表示機を再現するものです。

## 目的
本Webサイトは車内案内表示器を自由にシミュレートし、未だ見ぬ旅客案内装置を創造することを理念に、個人的な私利私欲のために作成しています。

## 機能
種別、行先、次の駅名、駅ナンバリング、路線カラーなど様々な項目を詳細に設定可能です。現在制作中のため、一部機能しないものがあります。

## その他
- 外部フォントとして「Nimbus Sans」を使用することがあります。
- トレインビジョン®は三菱電機株式会社の登録商標です。
- 不具合等は本リポジトリのIssue等にてご連絡願います。
