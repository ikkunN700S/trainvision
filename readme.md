# Train Vision Simulator
2026年10月01日更新（v1.1.8準拠）

## はじめに
本Webサイトはトレインビジョン®と呼ばれる近年列車内に搭載されることが増えてきた、LCD式旅客案内表示機を再現するものです。再現には外部の素材等を一切使用せず、純粋なCSS及びJavaScriptにて動作させています。

## 目的
本Webサイトは車内案内表示器を自由にシミュレートし、自分だけのオリジナル旅客案内装置を創造することを理念に掲げ、自己満足のために開発しています。

## 機能
種別、行先、駅名、駅ナンバリング、路線カラー、ニュース等、様々な項目を詳細に設定可能です。設定可能な項目は下部コントロール部にある項目となります。  
現在制作中のため、予告なく機能が削除されたり追加されたりすることがあります。また予期せぬバグ等により正常に動作しないことがありますが、予めご了承ください。

## 路線データプリセット
路線データをいくつかプリセットとして登録しています。これらを読み込んだ後、下部コントロール部にてそれぞれ編集可能です。  
現時点で駅数を増やすことはできませんが、プリセットとして読み込まれた駅数分編集することが可能です。なお、コントロール部には8駅ずつしか表示されないため、「次へ」「前へ」ボタンにより表示するデータを移動させつつ編集してください。
